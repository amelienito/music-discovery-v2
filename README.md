# Music Discovery V1

Une première version fonctionnelle de Music Discovery.

## Objectif

Explorer des références musicales, les écouter et indiquer rapidement si elles correspondent à l’univers recherché.

## Fonctionnalités prévues

- Affichage de références musicales
- Écoute d’extraits ou de morceaux
- Actions simples :
  - J’aime
  - Je n’aime pas
  - À écouter plus tard
- Interface visuelle claire et immersive
- Première base pour personnaliser les découvertes

## Installation

Aucune installation nécessaire.

Ouvrir simplement le fichier `index.html` dans un navigateur.
